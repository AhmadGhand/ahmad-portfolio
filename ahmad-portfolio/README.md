# Ahmad Ghandoura — Portfolio

A responsive React + Vite personal portfolio. The project is ready to customize and deploy on Vercel's free Hobby plan.

## Run locally

1. Install Node.js (version 20+).
2. Open this folder in Terminal.
3. Run `npm install`.
4. Run `npm run dev` and open the local URL shown.

## Customize before publishing

- Open `src/main.jsx` and update the `profile` object with your actual email, GitHub URL, and LinkedIn URL. These fields are deliberately blank rather than guessed.
- Add your CV as `public/resume.pdf`, then change `resume` to `'/resume.pdf'` in `src/main.jsx`.
- Add actual screenshots, repository URLs, and demos to each project once available. Project descriptions are preliminary and should be reviewed for accuracy.
- Edit education dates and certification titles if necessary.

## Deploy for free

1. Create a repository on GitHub and upload the contents of this folder.
2. Sign in to Vercel, choose **Add New → Project**, and import the GitHub repository.
3. Keep the auto-detected Vite settings and click **Deploy**.
4. Vercel provides a free `*.vercel.app` URL. A custom domain is optional.

This repository does not contain personal contact details or project source code. Only the portfolio site is included.
